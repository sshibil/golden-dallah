# Golden Dallah Wedding Services (الدلة الذهبية لخدمات الأفراح)

An ultra-luxury single-page web application built with **React**, **Tailwind CSS**, and **Framer Motion** for Golden Dallah Wedding Services, an established UAE luxury event catering and hospitality company operating since 1998.

---

## 🌟 Key Features

- **Dual Language Support (Arabic RTL & English LTR)**: Complete seamless language switcher dynamically toggling site layout (`dir="rtl"` / `dir="ltr"`), localized typography, and translations.
- **Ultra-Luxury Heritage Aesthetic**: Custom color palette featuring Deep Royal Emerald (`#0F2A23`), Metallic Gold accents (`#D4AF37`), Soft Ivory (`#FAF8F5`), and Off-Black (`#101815`).
- **Smooth Framer Motion Micro-Interactions**: Animated headers, interactive service modals, capacity scale tabs, step-by-step form transitions, and floating action elements.
- **Handcrafted Royal Dallah SVG Logo**: Custom vector artwork depicting traditional Emirati coffee pot with metallic gold gradient glows.
- **Interactive 4-Step Booking Inquiry Wizard**: Formats guest count, location across all 7 Emirates, event type, and special add-ons into a formatted WhatsApp inquiry link directly targeting `+971 50 667 2259`.
- **Direct VIP Communication Lines**: Click-to-call direct links for general booking (`+971 50 667 2259`) and VIP Direct Line (`+971 55 559 3389`).

---

## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or launch the included Node HTTP server:

```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your web browser.
